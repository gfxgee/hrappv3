Setup

composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm run build

Or the shortcut, which does all of the above:

composer setup

Day-to-day commands

Run the app

composer dev        # server + queue listener + vite, all at once
npm run dev         # vite only (Herd already serves the site)
npm run build       # production assets — required after any JS/TSX change

Test & lint

php artisan test --compact                      # whole suite
php artisan test --compact --filter=OnCall      # one file / pattern

vendor/bin/pint                                 # fix PHP style (run before committing)
npm run lint                                    # fix JS/TS
npm run types:check                             # tsc --noEmit
composer ci:check                               # everything CI runs

Inspect

php artisan route:list --except-vendor
php artisan schedule:list
php artisan config:show app.timezone
php artisan optimize:clear                      # clear config/route/view caches

Custom Artisan commands

CommandWhat it does
on-call:assign Records the on-call (“late dev”) developer for the current week. Skips anyone out the whole week; leaves a manual HR override alone.
on-call:notify-standin If the week’s on-call dev is out for a full day today, notifies the stand-in covering (in-app + Teams).
celebrations:trigger-flow
--force		 Fires the Teams celebrations flow with today’s birthdays and work anniversaries. No-op on empty days; --force sends anyway (handy for testing).
app:notify-celebrations Sends the in-app notification announcing today’s birthdays and anniversaries.
zkteco:refresh-employees Rebuilds the cached Active Employees map that gates the SharePoint Timekeeping mirror.
permissions:prune-orphaned Deletes permissions not in the canonical seeder set and detaches them from roles.
leave:import-sharepoint {path}
--dry-run		 One-off import of the legacy SharePoint Timeoff CSV into leave_requests. Upserts on the SharePoint id, so it’s safe to re-run.
overtime:import-sharepoint {path}
--dry-run		 Same, for the legacy Overtime CSV into over_time_requests.
Always dry-run the importers first. They resolve emails to user ids and skip rows with no matching user — --dry-run reports exactly what would import and what gets skipped, without writing.

JSON API

Read-only GET feeds consumed by the SharePoint / Power Automate → Teams automation. Base path /api. Every ?date= takes YYYY-MM-DD and falls back to today; every ?days= takes 1–365.

EndpointReturns
GET /api/leaves/todayEveryone on leave (excludes WFH). ?date=
GET /api/leaves/wfhEveryone working from home. ?date=
GET /api/reports/leave-summaryPer-active-employee leave & overtime totals for payroll. ?start= ?end=
GET /api/on-call/currentThe week’s on-call owner. ?date=
GET /api/on-call/todayWho is effectively on-call today (owner or stand-in). ?date=
GET /api/upcoming/leavesUpcoming leaves in the window. ?days=
GET /api/upcoming/birthdaysUpcoming birthdays. ?days=
GET /api/upcoming/anniversariesUpcoming work anniversaries. ?days=
GET /api/upcoming/holidaysUpcoming holidays. ?days=
POST /api/attendance/biometric-punchInbound biometric webhook (shared-secret header).

Leave payloads carry both type (display label, e.g. Sick Leave) and type_value (stable enum key, e.g. sick). Branch on type_value — labels may be reworded.

Full request/response reference: docs/api.md in the repo.

These GET feeds are unauthenticated. Fine for the internal automation, but don’t add anything sensitive to them without putting auth in front first.

Gotchas

  • Composer platform is pinned to PHP 8.3.20 in composer.json so the lockfile stays installable on the production server. Don’t remove it unless the server moves to 8.4+.
  • Frontend changes need a build. If a UI change isn’t showing, run npm run build (or npm run dev).
  • The mobile surface is excluded from Filament SPA mode. /m/* is in spaUrlExceptions because Inertia can’t boot via wire:navigate — removing it breaks mobile login.
  • Leave credits are per calendar year. Usage resets every Jan 1; only the current year counts against a quota.
  • On-call availability means full-day. A partial-day leave (e.g. 10:00–13:00) keeps someone on-call; WFH never counts as away.
  • Run Pint before committing — CI checks style.
  • Secrets live in .env only (Teams flow URLs, Graph credentials, webhook secrets). Never commit them or paste them into shared docs.
